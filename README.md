# Camerateka

**Не каталог. Не магазин. Не соцсеть. Система знаний о фотографии.**

Camerateka помогает понять фотографию через инструмент, а инструмент — через реальные
снимки и опыт сообщества. Камеры, объективы, люди и кадры связаны в один граф знаний,
а не разложены по отдельным страницам.

## Что уже работает

| Страница | Что делает |
|---|---|
| `index.html` | Виджет подбора: 5 уровней, объяснимый скоринг, «Камера дня» и рубрики |
| `camerateka.html` | Каталог 263 камер: фильтры, поиск, модалка-превью |
| `camera.html?id=` | Цифровой паспорт камеры: HUD, характер, эволюция, объективы, фирменное ПО |
| `kabinet.html` | Личный кабинет и фоторюкзак (пока в localStorage) |
| `admin.html` | Админка: камеры, объективы, скоринг, экспертный режим, фидбэк |

Разделы «Галереи», «Фотографы», «Модели», «Новости», «Форум» — заглушки, ждут наполнения.

## Данные

| Файл | Содержимое |
|---|---|
| `cameras.json` | 263 камеры: характеристики, цены вторичного рынка, эргономика, эволюция (`family`, `predecessorId`), затвор |
| `lens.json` | Объективы и совместимость по байонету |
| `scoring_config.json` | Вопросы, веса и правила подбора — правится без изменения кода |

Скоринг читает конфиг на лету: чтобы поменять вопрос или вес, код трогать не нужно.

## Как запустить

Статические файлы, сборка не нужна:

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`. Данные страницы берут из этого репозитория
(GitHub raw), поэтому локальные правки JSON видны после пуша.

## Сервер

Единственная серверная часть — [воркер сбора фидбэка](server/README.md) на бесплатном
тарифе Cloudflare Workers. Хранит только счётчики голосов «подходит?», без персональных
данных. Всё остальное — статика и localStorage.

## Принципы

Прежде чем добавить функцию, она проходит [четыре вопроса](docs/constitution.md):
делает ли фотографию понятнее, усиливает ли экосистему, помогает ли принять решение,
будет ли полезна через десять лет. Два «нет» — функция откладывается.
